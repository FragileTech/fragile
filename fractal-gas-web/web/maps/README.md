# SMB level maps

Full-level map images of every Super Mario Bros level (`mario-W-S.gif`,
worlds 1-8, stages 1-4), 1 map pixel = 1 world pixel, 224px tall (the NES
240px frame minus 8px overscan top and bottom). Used by the web UI's
"Level map — swarm" panel, which overlays every walker's RAM x-position
(`ram[0x6D]*0x100 + ram[0x86]`) on the map.

Source: https://ian-albert.com/games/super_mario_bros_maps/ (maps by Ian
Albert). Super Mario Bros is © Nintendo; these images are included for the
research demo only.
